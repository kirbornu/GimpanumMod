# GimpanumMod

Мод для Minecraft **1.21.1** / **NeoForge 21.1.228**.

Добавляет **Ядро** — креативный блок, который оператор настраивает на месте: привязывает к нему
ники игроков и задаёт события, срабатывающие при его уничтожении. При разрушении Ядро дропает
**Печать** — предмет, хранящий список привязанных ников, — выполняет настроенные команды для
каждого привязанного игрока и создаёт огненный взрыв.

Задуман для боёв на физических конструкциях (sublevel'ах) из модов **Sable** и
**Create Aeronautics**.

## Требования для сборки

- **JDK 21** (обязательно; NeoForge 21.1.x не запустится на 17)
- Gradle wrapper входит в репозиторий

```bash
./gradlew build
```

## Ключевая архитектурная особенность

Sable-sublevel — это **не отдельный `Level`**. Блоки конструкции лежат в родительском
`ServerLevel`, в скрытом резервном регионе чанков («плот»), а видимое положение получается
трансформацией через `Pose3d`. Поэтому `blockEntity.getBlockPos()` у Ядра на конструкции — это
служебная координата, а не та точка, где игроки видят блок. Все эффекты (взрыв, дроп, позиция
для команд) обязаны считаться от **мировой** позиции:

```
world = pose.position() + pose.orientation() * ((local - pose.rotationPoint()) * pose.scale())
```

Sable — **опциональная** зависимость: без неё мод работает, поддержка конструкций отключается.
